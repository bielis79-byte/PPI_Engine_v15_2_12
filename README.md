# PPI Engine v15.2.12

## Selección independiente por registro
- Nueva vista **Paneles independientes** en Segmentación.
- Cada registro se muestra en su propia gráfica Plotly.
- Cada registro conserva un tramo temporal diferente.
- La selección puede asignarse a una fase distinta por registro.
- Persistencia en SQLite y recuperación automática.
- Compatible con la pestaña Comparar y el motor predictivo.
